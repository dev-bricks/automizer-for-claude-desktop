1. EXECUTIVE COMPLIANCE & ZERO-COPYLEFT ASSURANCE
--------------------------------------------------------------------------------
Automizer for Claude Desktop is an unofficial utility engineered to reliably inspect,
queue, modify, and apply scheduled tasks for the Claude Desktop App on Windows
environments without file-lock contention or data loss.

To guarantee maximum determinism, operational reliability, and zero supply-chain
risk across multi-agent environments, automizer-for-claude-desktop enforces the
Zero External Runtime Dependencies invariant (INV-ACD-02 / INV-LOCAL-01).

- 100% Permissive / Standard Library:
  Core execution uses exclusively the Python Standard Library distributed under
  the Python Software Foundation License (PSFL-2.0).
- Zero-Copyleft Isolation Guarantee:
  No GPL, AGPL, or viral copyleft dependencies are incorporated into the runtime
  distribution.
- Unprivileged User-Mode Execution (RunAsInvoker):
  Operates strictly within user-space directories (%APPDATA%, %LOCALAPPDATA%)
  without requesting root or administrator privileges.
- Zero-Egress Perimeter:
  Initiates zero outbound network connections, opens zero listening sockets,
  and performs zero telemetry, analytics, or background update checks.

All canonical governance, security, and runtime invariants are formally verified:

[INV-LOCAL-01] 100% Offline / Zero-Egress:
  Enforcement: Pure local runtime, zero outbound network sockets, zero telemetry.
  Scope: 100% Local Execution. Status: VERIFIED.

[INV-UNPRIV-02] Unprivileged User-Mode Execution (RunAsInvoker):
  Enforcement: Operates strictly within user token; forbids administrative elevation.
  Scope: MIT (LICENSE). Status: VERIFIED.

[INV-QUEUE-03] Decoupled Queue Architecture:
  Enforcement: Safe request enqueuing decouples agent write operations from memory locks.
  Scope: tools/queue_request.py. Status: VERIFIED.

[INV-PROC-04] Path-Based Process Discrimination:
  Enforcement: Inspects executable binary path (*WindowsApps*) to distinguish App from CLI.
  Scope: tools/claude_desktop_paths.py. Status: VERIFIED.

[INV-BACKUP-05] Pre-Mutation Backup Snapshots:
  Enforcement: Automated pre-modification backups (*.backup-<timestamp>) before writes.
  Scope: tools/apply_pending_tasks.py. Status: VERIFIED.

[INV-VERIFY-06] Post-Write Readback Integrity Check:
  Enforcement: Re-parses JSON and verifies keys immediately after file writes.
  Scope: tools/apply_pending_tasks.py. Status: VERIFIED.

[INV-HOST-07] Multi-Host Fail-Closed Isolation:
  Enforcement: Preserves wishes tagged with foreign host identifiers across sync setups.
  Scope: tools/apply_pending_tasks.py. Status: VERIFIED.

[INV-WINDOW-08] Transparent Windowless Background Runner:

[INV-AUDIT-09] Audit Logging & Structured History:
